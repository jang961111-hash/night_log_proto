# Store Assets Checklist

이 문서는 App Store / Google Play 제출용 크리에이티브 산출물 체크리스트입니다.
기준일: 2026-02-24

## 1. 브랜드 기본
- 앱명: NightLog
- 서브 타이틀: 밤 3분, 오늘 감정 정리와 내일 실행 1개 확정
- 카테고리: Health & Fitness / Lifestyle 후보 검토
- 문의 이메일: support@nightlog.app

## 2. 아이콘/스플래시
- 앱 아이콘 원본 (1024x1024 PNG)
- Android Adaptive Icon foreground/background 분리
- iOS/Android 스플래시 배경색 일관성 점검
- 파비콘(웹) 포함

## 3. 스크린샷 세트
### 3.1 App Store (iPhone)
- 6.7" 기준 5~8장
- 권장 흐름
  1. 랜딩 가치 제안
  2. 음성 대화 시작 화면
  3. 결과(요약 + 감정 그래프)
  4. 일정 조절
  5. 캘린더 인사이트

### 3.2 Google Play
- 휴대전화 스크린샷 2~8장
- 16:9 또는 9:16 비율 유지
- 첫 2장에 핵심 가치 문구 배치

## 4. 스토어 카피
- 한 줄 설명 (80자 내)
- 상세 설명 (기능/가치/안전성 포함)
- 키워드 후보 10개
- 업데이트 노트 템플릿

## 5. 현지화
- 기본: ko-KR
- 확장 후보: en-US, ja-JP
- 스크린샷 카피와 앱 내 카피 용어 일치

## 6. 품질 체크
- 이미지 내 오탈자/정렬 점검
- 최신 UI와 스크린샷 불일치 여부 확인
- 정책 문서(이용약관/개인정보) 링크 노출 확인
- 다크모드 미지원 시 스토어 설명에 명시

## 7. 운영 규칙
- 릴리즈 브랜치마다 스크린샷 세트 버전 태깅
- 기능 변경이 스크린샷과 충돌하면 제출 전 재촬영
- 스토어 심사 거절 사유 발생 시 수정 이력 기록
